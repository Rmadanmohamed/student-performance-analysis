# Student Performance Analysis

## Overview
A data science project for analyzing student exam performance and clustering patterns with K-Means.

## Problem Statement
Education analytics benefits from exploratory analysis and clustering to understand score patterns across student groups.

## Features
- Student performance EDA
- Visualization notebook
- K-Means clustering notebook

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
- StudentsPerformance.csv

## Models / Algorithms
- K-Means clustering

## Results
The notebooks are exploratory; no final supervised metric was detected.

## Project Structure
- notebooks/
  - student-performance-analysis.ipynb
  - student-performance-kmeans-clustering.ipynb

## How to Run
- `pip install -r requirements.txt`
- `jupyter notebook notebooks/student-performance-analysis.ipynb`
