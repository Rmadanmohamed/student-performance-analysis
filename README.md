# Student Performance Analysis

## Overview and problem statement

Explore student exam scores and group patterns using descriptive plots and unsupervised clustering for educational analytics.

## Technology stack and prerequisites

Python 3 and a notebook runtime are required (exact Python version unspecified). [requirements.txt](requirements.txt) declares matplotlib, numpy, pandas, scikit-learn, seaborn; no exact versions are pinned. Local Jupyter must be installed separately. No GPU requirement is documented.

- [student-performance-kmeans-clustering.ipynb](notebooks/student-performance-kmeans-clustering.ipynb) — notebook source.
- [requirements.txt](requirements.txt) — dependencies.
- [LICENSE](LICENSE) — repository license, separate from dataset rights.

## Dataset and preprocessing

Supply `StudentsPerformance.csv` (not included; provenance and license unspecified). Columns used include math, reading and writing scores, gender, race/ethnicity, parental education, lunch and preparation course. The clustering notebook renames columns and label-encodes parent education, preparation and lunch.

## Model and workflow

EDA uses pairplots, group bar charts and countplots. K-means evaluates inertia for 2–24 clusters (`n_init=20`) and fits an eight-cluster model with k-means++ initialization. Cluster averages and ranks are computed from exam scores.

## Usage, evaluation and limitations

Run the EDA notebook to produce charts; the clustering notebook reads both `/content/StudentsPerformance.csv` and `../content/StudentsPerformance.csv` and uses columns from position 2 onward. A later cell begins `1def` and is invalid Python; execute valid cells individually. No saved metrics or plots found. Unscaled score features and ordinal-coded categories may distort distances; group comparisons are descriptive, not causal or appropriate for high-stakes student decisions.
